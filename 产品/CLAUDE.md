## Project Overview

This is a product image catalog for a Chinese electrical equipment company. It contains ~312 image files (JPG, PNG, WebP) organized into 14 product category directories — no source code, build system, or runtime.

## Image Types

- **`微信图片_YYYYMMDDHHMMSS.jpg`** — Product photos sourced via WeChat, mostly dated February 2024
- **`Mokker.png` / `Mokker (N).png`** — 3D rendered product mockups
- **`R-C.jpg` / `R-C*.png`** — Technical schematics/wiring diagrams
- **Hash-named files** (e.g., `03166f3186790f4332a036f03be96ab.jpg`) — Miscellaneous product images
- **`6a7cf0773f0f145702447a3f4b8b90b.jpg`** (root) — Company logo
