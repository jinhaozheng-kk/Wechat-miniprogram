## 一、项目背景与目标

### 1.1 背景

华信通讯科技有限公司主营建筑电气箱体产品，涵盖等电位联结端子箱、防雷测试箱、消防端子箱、光纤入户箱等14个品类。当前产品信息主要以图片形式存储，缺乏线上展示渠道，客户（工程商/施工方）询价依赖电话或微信沟通，效率较低。

### 1.2 目标

- 建立专业的线上产品展示平台，提升品牌形象
- 简化工程商询价流程，降低销售沟通成本
- 提供产品选型辅助工具，帮助客户快速定位所需产品
- 积累潜在客户线索（询价信息）

### 1.3 范围

微信小程序（客户端）+ 轻量级管理后台（运营端），暂不涉及在线支付/下单功能。

## 二、用户分析

### 2.1 主要用户：工程商 / 施工方

| 属性 | 描述 |
|------|------|
| 使用场景 | 项目投标备料阶段查询产品规格；现场施工时确认安装尺寸；向甲方汇报时展示产品 |
| 核心诉求 | 快速找到合适产品规格、了解材质/尺寸、方便批量询价 |
| 使用习惯 | 主要使用手机微信，习惯转发链接分享给同事或甲方 |
| 痛点 | 传统方式需要打电话或微信沟通才能获取规格和报价，效率低 |

### 2.2 次要用户：公司销售/运营人员

| 属性 | 描述 |
|------|------|
| 使用场景 | 通过管理后台维护产品信息、处理询价单、查看客户留资 |
| 核心诉求 | 便捷地更新产品图片和规格、及时获取询价通知 |

## 四、功能需求

### 4.1 首页

**功能描述**：小程序入口页，展示品牌形象和核心导航

**内容模块**：
- 公司Logo + 横幅（Banner轮播，展示主推产品或活动）
- 产品分类入口（图标宫格，显示全部14个类别）
- 快捷询价入口（固定悬浮按钮）
- 公司简介摘要 + "了解更多"跳转

**交互要求**：
- Banner支持后台配置轮播图，可链接到具体产品
- 产品分类图标点击进入对应分类列表页

---

### 4.2 产品分类列表页

**功能描述**：展示某一类别下的所有产品型号

**内容模块**：
- 顶部：分类名称 + 分类简介（一句话）
- 产品卡片列表（图片 + 产品名称 + 核心规格摘要）
- 搜索框（支持按产品名称/型号搜索）
- 筛选功能（按材质、尺寸范围等，待产品规格录入后上线）

**交互要求**：
- 产品卡片点击进入产品详情页
- 支持长按卡片"加入对比"（触发产品对比功能）

---

### 4.3 产品详情页

**功能描述**：展示单个产品的完整信息

**内容模块**：
- 产品图片轮播（支持多图，含3D渲染图和实物照片）
- 产品名称 + 型号
- 产品规格参数表（结构化展示，初期人工录入）：
  - 外形尺寸（长×宽×高，单位mm）
  - 材质（镀锌板 / 不锈钢 / ABS等）
  - 安装方式
  - 适用场景
  - 执行标准/认证
  - 其他特殊参数（按品类定义）
- 产品描述（富文本，可包含安装示意图）
- 操作按钮：**立即询价**（主按钮）+ **加入对比**（次要按钮）
- 分享按钮（微信好友 / 朋友圈）

**交互要求**：
- 图片支持放大预览
- 规格参数支持一键复制
- "立即询价"跳转至询价表单，并预填产品信息

---

### 4.4 在线询价

**功能描述**：工程商提交采购需求，等待销售回复

**询价表单字段**：

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| 询价产品 | 是 | 可从详情页带入，也可手动选择（支持多个产品） |
| 数量/规格需求 | 是 | 文本输入，描述需求 |
| 工程名称 | 否 | 便于报价单归档 |
| 联系人姓名 | 是 | — |
| 联系电话 | 是 | 正则验证手机号格式 |
| 所在城市 | 否 | 省/市二级联动选择器 |
| 备注 | 否 | 其他说明，最多200字 |

**提交后流程**：
1. 小程序端：显示"询价成功"提示页，注明"销售将在1个工作日内联系您"
2. 后台端：收到新询价通知（微信订阅消息 + 管理后台提醒）
3. 询价记录存档，支持后台导出Excel

**历史询价**：
- 用户授权登录后，可在"我的"页面查看本人历史询价记录及处理状态

---

### 4.5 产品对比 / 选型

**功能描述**：帮助工程商对比多款产品规格，辅助选型决策

**交互流程**：
1. 在产品列表页或详情页，点击"加入对比"（最多同时对比4款）
2. 屏幕底部出现"已选N款，开始对比"悬浮条
3. 点击进入对比页，横向展示各产品规格参数

**对比页内容**：
- 顶部：各产品缩略图 + 名称（可移除）
- 参数对比表：逐行展示规格项，差异项高亮显示
- 每款产品下方：**立即询价**按钮（预填该产品信息）

**限制**：
- 仅支持同类别产品对比（跨类别对比参数体系差异较大，暂不支持）

---

### 4.6 关于我们

**内容模块**：
- 公司简介（图文混排）
- 资质证书展示（图片轮播）
- 联系方式：电话（点击可拨打）、地址（点击跳转地图）、邮箱
- 关注公众号引导（可选）

---

### 4.7 我的（用户中心）

**功能描述**：微信授权登录后可用

**内容模块**：
- 头像 + 微信昵称
- 历史询价记录（列表 + 状态：待处理 / 已联系 / 已成交）
- 收藏的产品（可从详情页收藏）
- 联系客服（跳转微信客服或在线留言）

## 五、管理后台需求（轻量级Web端）

后台面向公司内部运营人员，提供产品内容维护和询价管理功能。

| 模块 | 功能 |
|------|------|
| 产品管理 | 新增/编辑/删除产品；上传图片；录入规格参数 |
| 分类管理 | 管理14个产品类别名称和封面图 |
| 询价管理 | 查看询价列表；更新处理状态；备注跟进记录；导出Excel |
| Banner管理 | 配置首页轮播图及跳转链接 |
| 消息通知 | 新询价时推送微信订阅消息给指定销售人员 |

## 六、非功能需求

| 类型 | 要求 |
|------|------|
| 性能 | 产品列表页首屏加载 < 2秒；图片懒加载 |
| 兼容性 | 兼容iOS 14+ / Android 8+；微信基础库 3.0+ |
| 图片规范 | 产品主图建议800×800px以上，支持JPG/PNG/WebP |
| 数据安全 | 用户手机号等敏感信息加密存储，不对外暴露 |
| 隐私合规 | 收集用户信息前需获得授权，提供隐私政策 |

## 七、数据准备计划（上线前工作）

由于当前仅有图片资产，上线前需完成以下数据准备工作：

1. **产品规格录入**：整理各类产品的规格参数，按统一模板录入管理后台（建议优先完成图片最多的5个类别）
2. **图片整理**：清理重复图片，为每款产品选择1张主图 + 若干细节图
3. **产品型号梳理**：确定各类别下有哪些具体型号（如等电位联结端子箱分几个尺寸系列）
4. **公司信息录入**：公司简介、资质证书、联系方式

## 八、技术架构建议

| 层次 | 技术选型 | 理由 |
|------|----------|------|
| 小程序前端 | 微信小程序原生（WXML/WXSS） | 性能最优，无需多端适配 |
| 管理后台 | Vue 3 + Element Plus | 快速搭建，组件丰富 |
| 后端API | Node.js (Express/Koa) 或 Java (Spring Boot) | 根据开发团队技术栈决定 |
| 数据库 | MySQL | 关系型数据，适合产品规格结构化存储 |
| 图片存储 | 腾讯云COS 或 阿里云OSS | CDN加速，与微信小程序生态兼容性好 |
| 部署 | 腾讯云服务器（小程序域名需备案） | — |

## 十、待确认事项

在正式启动开发前，以下问题需与公司确认：

1. **产品型号梳理**：各类别下具体有哪些型号，是否有型号编码体系？
2. **询价处理流程**：询价通知发给哪位销售？是否需要多人协作跟进？
3. **价格展示策略**：产品详情页是否展示价格？（建议工程商类场景不公开标价，以"面议/询价"为主）
4. **小程序主体资质**：公司是否已有微信小程序账号或公众号？（注册需要营业执照等资料）
5. **开发资源**：是自有开发团队，还是外包？这决定技术选型和工期估算的精度。
